# Changelog

All notable changes to this project are documented here.

## 0.1.0 - 2026-09-02

- Add the router, finder, interpreter, and comparator Skills.
- Add deterministic PDF, artifact, classification, report-structure, and
  relationship validators.
- Add official Mermaid syntax parsing to the Markdown publication audit.
- Add capability-scoped standalone Skills, a materialized repository plugin,
  and compatible shared runtime and renderer reuse.
- Add local wheel and source-distribution builds, offline tests, compatibility
  CI, and cross-renderer Markdown quality gates.
